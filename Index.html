Objetivo del Portafolio

El objetivo al crera este portafolio es recopilar todo lo hecho durante el semestre, agregando el cas del figma que se se nos dio a escoger desde el principo del parcial, mediante diversas practicas que llevamos acabo al principio del parcial hasta ya lo ultimo, utilizamos formularios, mediante el uso de herramientas como lo fue el htm, css, js incluiisve java y mysql, todo eso se vio reflejado atraves del ultimo trabajo quee fue el CRUD pero, esta pagina toma ese ejercicio y todos los ejercicios hechos durante los 3 parciales llevados a cabo.

Qué aprendimos?

Vimos cómo crear páginas web con HTML, darles estilo con CSS y añadir interactividad con JavaScript.

Aprendimos a crear formularios, validar datos y organizar el contenido para mostrar nuestro trabajo de manera efectiva.

También reforzamos el uso de nuevas tecnologías y herramientas de desarrollo, y cómo documentar cada práctica de forma clara.

En resumen, este portafolio es una recopilación de todo lo aprendido y realizado durante el parcial, mostrando nuestro progreso y habilidades en el desarrollo web.
