Objetivo del Portafolio

El objetivo de este portafolio es reunir los trabajos del parcial en un solo lugar, mostrando cada práctica con su enlace directo para revisarla rápidamente.

Incluye ejercicios de formulario, validación, cálculos en JavaScript y la presentación de una página de inicio personal.

Qué aprendimos

Aprendimos a crear páginas web con HTML, a darles estilo con CSS y a añadir interactividad con JavaScript. Realizamos formularios, validamos datos, resolvimos ejercicios matemáticos y organizamos el contenido con un portafolio funcional.
